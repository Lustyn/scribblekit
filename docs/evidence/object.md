# Evidence ledger: objects (`fmt-object`, `fmt-common`)

Every JSON field name, enum value name and flag bit name that `fmt-object` (`.so`, `.sao`, `.sa`,
`.odt`, the shared trigger / action / modifier schema used by `.sod` and event scripts) and
`fmt-common` (`.dps`) print, with the engine code or game text it comes from. Format and kinds
as in [README.md](README.md): **code** = read and used by the engine as described, **unused** =
the loader discards it / nothing reads it (the reader is cited), **text** = named by the game's
own strings (`data\events\[region]\static_*` text tables, debug strings), **data-only** = no
code path found (the row says what was searched). The key citation is repeated in each field's
doc comment (or the comment above its schema table entry).

How the evidence was gathered: loaders and parse methods were read in `re/decompiled.c` and,
where Ghidra had not defined the function (e.g. the `.so` loader `FUN_006bbd70`), decompiled
headless from `re/project`; trigger / action / modifier classes were resolved through their
factory switch to the constructor's vtable (trigger text table = slot `+0x30`, action text
table = slot 13 / `+0x34`, parse = trigger slot 8 / action slot 9 / modifier slot 5). Each stored
runtime offset was followed to the code that uses it. Every hypothesis was checked with Python
over all shipped files (6071 `.so`, 1575 `.sa`, 13 `.sao`, 202 `.dps`, 122 `.sod`, the event
scripts and `scribbleobject.odt`).

## Corrections made while building this ledger

Names that were wrong before (old -> new JSON):

* `.odt`: all seven fields are bools (`FUN_0057c910`); `humanoid` -> `two_genders` (set on exactly
  the 692 objects with gender `both`); `field_3` -> `uncopyable`; `raw` -> `verbatim_message`. The
  exe has no `FileDescriptorProto` for `ObjectDetails` (lite runtime), so no names come from it.
* `DependencyKind` 7 (was numeric) -> `audio` (`FUN_00494b60`: 7 -> cache type 6, streaming audio).
* `.so`: `default_gender` numbers -> `random`/`male`/`female` (`FUN_006c05f0`);
  `attached_part_count` -> `jointed_part_count`; body flags `ground_vehicle`/`air_vehicle` -> one
  4-bit `vehicle_control` mode; `size_fit` `at_least`/`at_most` -> `not_larger`/`not_smaller`
  (direction was reversed); container flag `locked` -> `contents_keep_position`; layer flags
  `foreground` -> `sky_object`, `carry_upright` -> `rotatable`; `shock_mode` numbers -> names;
  `stick_mode` `normal` -> `none`; `combustion` 2-8 -> explosion sizes / `burns`; `rigid` ->
  `rotates` (it is read: 0 locks rotation); `freeze_temperature`/`burn_temperature` ->
  `cold_temperature`/`hot_temperature` (thresholds of the become-cold/warm/hot triggers); swim/air
  attack durations -> `unused_*` (skipped by `FUN_006677a0`).
* Node tree: `MeshPart.part` is a draw order, not a bone id (JSON `draw_order`; the atlas piece is
  the part's tree-order index); `MeshPart.layer` is a body-part class (JSON `body_part`);
  `Outline.closed` -> `platform` (one-way platform); a box zone with no parameter block is a solid
  box, not a sensor; atlas `body_parts` (six bytes) -> `unused_mirror_map`, `skipped` -> `unused`;
  `HitBoxes.boxes` -> `animation_boxes` (one per animation slot); hotspot `unused_0f` ->
  `bare_rope_anchor`, `removed_0d` -> `unused_0d`.
* Triggers: `zone_kind_2`/`zone_kind_3` -> `water`/`lava`; `unknown_15`/`unknown_42`/`unused_3c` ->
  `never_fires_*`; `merit` status flags `not_earned/earned/revealed` -> `not_earned/disabled/earned`.
* Actions: `set_interrupt_flag` bit 6 is part of `channel`; `add_portal_choice` level fields are a
  level descriptor (`tile_map`/`scene`/`setup`/`merits`); `spray` `create_emitter`/`emitter` ->
  `launch_point_is_id`/`launch_point`; `modify_attitudes` `unused` -> constant `separator`.
* Properties: 0x22 `grounded` -> `sky_object`, 0x41 `functional` -> `can_move`; `reaction`,
  `survival_role`, `disabled`, `inert`, `dry` -> `unused_*` (no reader / no apply case).

Requests from other codec owners are answered in [requests-behaviour.md](requests-behaviour.md).
